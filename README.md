# Лабораторная работа 4. Цветокоррекция с матричным преобразованием

Курс «Компьютерное зрение». По снимку сцены с мишенью X-Rite ColorChecker находится матрица цветокоррекции (CCM) 3×3, фотография корректируется, точность оценивается по ΔE76. Цвет реального объекта, рассчитанный по спектрам лампы и объекта, сравнивается с его цветом на фото до и после коррекции.

## Что внутри

| Путь | Содержимое |
|---|---|
| `lab4_color_correction.ipynb` | Основной ноутбук: код, графики, выводы (с сохранёнными результатами) |
| `photo/IMG_20261003_152704.jpg` | Исходный снимок (vivo V27e, Display P3) |
| `031026-light-6.csv` | Спектр лампы, мВт/(м²·нм), 380–730 нм |
| `031026-objects-6.csv` | Спектральное отражение объектов, % (используется строка 2 — оранжевый) |
| `results/` | Скорректированное фото и все графики |
| `docs/index.html` | Интерактивный разбор проекта: теория, расчёты на данных, вопросы для защиты |

## Результаты

| ΔE76 | до коррекции | после коррекции |
|---|---|---|
| все 24 поля, среднее | 9.88 | 6.04 |
| 6 проверочных полей, среднее | 12.58 | 6.53 |

- ColorChecker находится автоматически собственным алгоритмом: порог, морфология, контуры, кластеризация, подгонка решётки 4×6 через гомографию (DLT).
- Лампа: ≈2694 K, ≈58 лк.
